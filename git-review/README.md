# Git Review

Run **Git Review: Toggle** from the command palette. The sidebar shows recent
commits as an expandable tree. Expand a commit to see its changed files. Click a
file, or select it and press Enter. The main editor opens a side-by-side diff
with syntax highlighting. Press `n` or `p` in the diff to move between changes.

The file status colors use the active Fresh theme. Use the `×` button or run
**Git Review: Toggle** again to close the review. Run **Git Review: Refresh** to
read the latest commits.

Fresh does not let a plugin replace the built-in file explorer list. This plugin
adds a separate commit review section to the sidebar.
