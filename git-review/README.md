# Git Review

Run **Git Review: Toggle** from the command palette. The sidebar shows recent commits and the files changed by the selected commit. Select a file to open its patch in the editor. The `×` button or the same command closes the review and restores the normal sidebar. Run **Git Review: Refresh** to read the latest commits.

This plugin uses its own sidebar section. Fresh does not let plugins replace the built-in file explorer's file list.
